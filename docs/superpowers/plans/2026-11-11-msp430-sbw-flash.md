# MSP430F5529 Spy-Bi-Wire Flash Programming (Phase A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the probe erase, program, verify and read an MSP430F5529 over Spy-Bi-Wire, driven by a Python CLI, without changing the USB descriptors or the SWD function.

**Architecture:** A PIO program on PIO1 clocks JTAG cycles onto the two SWD pins. A pure C++ library (`lib/msp430`) turns IR/DR shifts into cycle vectors (`SbwTap`), ports TI's CPUXv2 sequences (`Cpuxv2`), and parses a CMSIS-DAP vendor command (`Session`). The DAP engine gets an optional vendor hook; glue in `src/` wires it together. The host tool in `tools/msp430/` owns the device table, image parsing and the erase/write/verify flow.

**Tech Stack:** Zephyr 4.4.0, pico-sdk PIO HAL via `pio_rpi_pico`, pioasm, C (driver), C++20 (library and glue, no heap/exceptions/RTTI), Python 3 + pyusb (host tool), TI SLAU320 `Replicator430Xv2` (BSD-3-Clause) as the reference.

**Spec:** `docs/superpowers/specs/2026-11-11-msp430-sbw-design.md`

## SBW in one page

One JTAG clock cycle is three SBWTCK low pulses ("slots"). SBWTCK idles high.

| Slot | Who drives SBWTDIO | What happens |
|---|---|---|
| TMS | probe | value set while the clock is high; in the "LDH" variant the probe raises the line during the low phase |
| TDI | probe | value set while the clock is high |
| TDO | target | probe releases the line, target drives it during the low phase, probe samples at the end of the low phase |

While the TAP is in Run-Test/Idle, the TDI slot value is the CPU clock input TCLK. Two consequences, both copied from TI's code:

- A shift must leave and re-enter Run-Test/Idle with TDI equal to the current TCLK level.
- Changing TCLK while it is high must use the LDH variant in the TMS slot, otherwise TCLK glitches low.

A low phase longer than about 7 µs resets the target's SBW logic. The PIO program therefore only ever waits with the clock high.

```cpp
#include "testing.hpp"
#include "mock_swd_driver.hpp"
#include "dap/engine.hpp"

#include <algorithm>
#include <vector>

namespace {

struct RecordingVendor : dap::VendorHandler {
	std::vector<uint8_t> last_request;
	std::vector<uint8_t> reply; /* empty -> decline */
	int calls = 0;

	size_t handle(std::span<const uint8_t> request, std::span<uint8_t> response) override
	{
		++calls;
		last_request.assign(request.begin(), request.end());
		if (reply.empty() || reply.size() > response.size()) {
			return 0;
		}
		std::copy(reply.begin(), reply.end(), response.begin());
		return reply.size();
	}
};

struct Fixture {
	MockSwdDriver drv;
	MockHostStatus host;
	dap::Config cfg;
	dap::DapEngine engine{drv, host, cfg};
	RecordingVendor vendor;

	std::vector<uint8_t> run(std::initializer_list<uint8_t> req)
	{
		uint8_t resp[256] = {};
		size_t n = engine.process({req.begin(), req.size()}, resp);
		return {resp, resp + n};
	}
};

} // namespace
```

```cpp
/* Optional handler for the vendor command IDs 0x80..0x9F. */
class VendorHandler {
public:
	virtual ~VendorHandler() = default;
	/* `request` starts at the command ID byte and runs to the end of the
	 * packet. `response` is the remaining response buffer (at least 2
	 * bytes). Return the number of response bytes written (response[0]
	 * must be the command ID), or 0 to decline; the engine then answers
	 * with the default one-byte echo. A handled command consumes the rest
	 * of the request packet. */
	virtual size_t handle(std::span<const uint8_t> request,
			      std::span<uint8_t> response) = 0;
};
```

`lib/msp430/include/msp430/sbw_port.hpp`:

```cpp
#pragma once
/* Hardware abstraction for the two SBW wires. The PIO driver implements it on
 * target; host tests use a recording mock.
 */
#include <cstdint>

namespace msp430 {

class SbwPort {
public:
	virtual ~SbwPort() = default;

	/* Take both pins and drive SBWTCK low, SBWTDIO high. Returns false if
	 * the pins are owned by SWD. */
	virtual bool acquire() = 0;
	/* Both pins high-impedance. */
	virtual void release() = 0;
	/* SBWTCK frequency while clocking cycles. */
	virtual void set_clock(uint32_t slot_hz) = 0;

	/* Static levels and a single short low pulse on SBWTCK; used only by
	 * the entry sequence. */
	virtual void set_tck(bool level) = 0;
	virtual void set_tdio(bool level) = 0;
	virtual void tck_pulse() = 0;

	/* Clock `count` (1..32) JTAG cycles. Bit i of tms/tdi belongs to cycle
	 * i. Returns the sampled TDO bits, bit i from cycle i. */
	virtual uint32_t cycles(uint32_t tms, uint32_t tdi, unsigned count) = 0;
	/* One Run-Test/Idle cycle (TMS = 0) that sets TCLK to `level`.
	 * `was_high` selects the TMSLDH variant of the TMS slot. */
	virtual void tclk_cycle(bool was_high, bool level) = 0;

	virtual void delay_us(uint32_t us) = 0;
	virtual uint32_t millis() = 0;
};

} // namespace msp430
```

```cpp
#pragma once
/* MSP430 JTAG primitives. Cpuxv2 is written against this interface; SbwTap
 * implements it over an SbwPort, and host tests script it directly.
 */
#include <cstdint>

namespace msp430 {

enum class Entry : uint8_t { RstHigh, RstLow };

class Tap {
public:
	virtual ~Tap() = default;

	virtual void set_speed(uint32_t slot_hz) = 0;
	/* Release the pins, let the target's test logic reset, take the pins.
	 * Returns false if the pins are not available. */
	virtual bool open() = 0;
	/* SBW entry sequence followed by a TAP reset. Leaves the TAP in
	 * Run-Test/Idle with TCLK high. */
	virtual void enter(Entry entry) = 0;
	/* Release the pins. */
	virtual void close() = 0;

	/* All shifts start and end in Run-Test/Idle. */
	virtual uint8_t ir_shift(uint8_t ir) = 0; /* returns the captured IR (JTAG ID) */
	virtual uint16_t dr_shift16(uint16_t value) = 0;
	virtual uint32_t dr_shift20(uint32_t value) = 0;
	virtual void set_tclk() = 0;
	virtual void clr_tclk() = 0;

	virtual void delay_ms(uint32_t ms) = 0;
	virtual uint32_t millis() = 0;
};

} // namespace msp430
```

```cpp
/* Tap over Spy-Bi-Wire: builds the per-cycle TMS/TDI vectors that TI's
 * IR_Shift / DR_Shift16 / DR_Shift20 / AllShifts / ResetTAP / SetTCLK_sbw /
 * ClrTCLK_sbw produce (slau320, LowLevelFunc430Xv2.c, JTAGfunc430Xv2.c).

#include "msp430/sbw_port.hpp"
#include "msp430/tap.hpp"

namespace msp430 {

class SbwTap final : public Tap {
public:
	explicit SbwTap(SbwPort &port) : port_(port) {}

	void set_speed(uint32_t slot_hz) override { port_.set_clock(slot_hz); }
	bool open() override;
	void enter(Entry entry) override;
	void close() override { port_.release(); }

	uint8_t ir_shift(uint8_t ir) override;
	uint16_t dr_shift16(uint16_t value) override;
	uint32_t dr_shift20(uint32_t value) override;
	void set_tclk() override;
	void clr_tclk() override;

	void delay_ms(uint32_t ms) override { port_.delay_us(ms * 1000u); }
	uint32_t millis() override { return port_.millis(); }

	/* 6x TMS=1 to Test-Logic-Reset, then one TMS=0 to Run-Test/Idle. */
	void reset();

private:
	uint32_t scan(bool ir, unsigned nbits, uint32_t data);

	SbwPort &port_;
	bool tclk_ = true; /* TI: TCLK_saved starts high */
};

} // namespace msp430
```

```cpp
#include <cstdio>
#include <deque>
#include <string>
#include <vector>

#include "msp430/sbw_port.hpp"

class MockSbwPort : public msp430::SbwPort {
public:

		TLR, RTI, SelDR, CapDR, ShDR, Ex1DR, PauDR, Ex2DR, UpdDR,

	};
	struct Scan {
		bool ir;
		unsigned nbits;
		uint32_t value; /* first shifted bit is the MSB */
		bool operator==(const Scan &o) const
		{
			return ir == o.ir && nbits == o.nbits && value == o.value;
		}
	};

	/* --- scripting --- */
	bool acquire_ok = true;
	std::deque<uint32_t> tdo_script; /* one entry per cycles() call; default 0 */
	uint32_t millis_now = 0;
	uint32_t millis_step = 1; /* added on every millis() call */

	/* --- recordings --- */
	std::vector<std::string> log; /* every call, in order */
	std::vector<CycleCall> cycle_calls;
	std::vector<Scan> scans;      /* decoded IR/DR scans */
	TapState state = TLR;
	bool tclk_outside_rti = false; /* set if tclk_cycle ran outside Run-Test/Idle */
	uint32_t clock_hz = 0;

	bool acquire() override
	{
		log.push_back("acquire");
		return acquire_ok;
	}
	void release() override { log.push_back("release"); }
	void set_clock(uint32_t hz) override
	{
		clock_hz = hz;
		log.push_back("clock:" + std::to_string(hz));
	}
	void set_tck(bool level) override { log.push_back(level ? "tck:1" : "tck:0"); }
	void set_tdio(bool level) override { log.push_back(level ? "tdio:1" : "tdio:0"); }
	void tck_pulse() override { log.push_back("pulse"); }

	uint32_t cycles(uint32_t tms, uint32_t tdi, unsigned count) override
	{
		char buf[48];
		std::snprintf(buf, sizeof(buf), "cycles:%x:%x:%u", (unsigned)tms,
			      (unsigned)tdi, count);
		log.push_back(buf);
		cycle_calls.push_back({tms, tdi, count});
		for (unsigned i = 0; i < count; ++i) {
			step((tms >> i) & 1u, (tdi >> i) & 1u);
		}
		uint32_t tdo = 0;
		if (!tdo_script.empty()) {
			tdo = tdo_script.front();
			tdo_script.pop_front();
		}
		return tdo;
	}

	void tclk_cycle(bool was_high, bool level) override
	{
		log.push_back(std::string("tclk:") + (was_high ? "1" : "0") + ">" +
			      (level ? "1" : "0"));
		if (state != RTI) {
			tclk_outside_rti = true;
		}
		step(false, level);
	}

	void delay_us(uint32_t us) override { log.push_back("delay:" + std::to_string(us)); }
	uint32_t millis() override
	{
		millis_now += millis_step;
		return millis_now;
	}

private:
	static TapState next(TapState s, bool tms)
	{
		switch (s) {
		case TLR:   return tms ? TLR : RTI;
		case RTI:   return tms ? SelDR : RTI;
		case SelDR: return tms ? SelIR : CapDR;
		case CapDR: return tms ? Ex1DR : ShDR;
		case ShDR:  return tms ? Ex1DR : ShDR;
		case Ex1DR: return tms ? UpdDR : PauDR;
		case PauDR: return tms ? Ex2DR : PauDR;
		case Ex2DR: return tms ? UpdDR : ShDR;
		case UpdDR: return tms ? SelDR : RTI;
		case SelIR: return tms ? TLR : CapIR;
		case CapIR: return tms ? Ex1IR : ShIR;
		case ShIR:  return tms ? Ex1IR : ShIR;
		case Ex1IR: return tms ? UpdIR : PauIR;
		case PauIR: return tms ? Ex2IR : PauIR;
		case Ex2IR: return tms ? UpdIR : ShIR;
		case UpdIR: return tms ? SelDR : RTI;
		}
		return TLR;
	}

	void step(bool tms, bool tdi)
	{
		if (state == ShDR || state == ShIR) {
			shift_value_ = (shift_value_ << 1) | (tdi ? 1u : 0u);
			++shift_bits_;
		}
		state = next(state, tms);
		if (state == UpdDR || state == UpdIR) {
			scans.push_back({state == UpdIR, shift_bits_, shift_value_});
			shift_value_ = 0;
			shift_bits_ = 0;
		}
	}

	uint32_t shift_value_ = 0;
	unsigned shift_bits_ = 0;
};
```

```cpp
/* ResetTAP (JTAGfunc430Xv2.c): six cycles with TMS high reach
 * Test-Logic-Reset from any state, one cycle with TMS low enters
 * Run-Test/Idle. TDI stays high throughout, so TCLK ends high. */
void SbwTap::reset()
{
	port_.cycles(0x3F, 0x7F, 7);
	tclk_ = true;
}

/* One complete scan, as IR_Shift / DR_Shift16 / DR_Shift20 + AllShifts do:
 *
 *   IR: cycle 0 (TMS 1, TDI = TCLK)  Run-Test/Idle -> Select-DR
 *       cycle 1 (1, 1)               -> Select-IR
 *       cycle 2 (0, 1)               -> Capture-IR
 *       cycle 3 (0, 1)               -> Shift-IR
 *   DR: cycle 0 (TMS 1, TDI = TCLK)  Run-Test/Idle -> Select-DR
 *       cycle 1 (0, 1)               -> Capture-DR
 *       cycle 2 (0, 1)               -> Shift-DR
 *   then `nbits` data cycles, MSB first, TMS high on the last one (Exit1),
 *   then (1, 1) Update and (0, TDI = TCLK) back to Run-Test/Idle.
 *
 * TDI follows the saved TCLK level on the first and last cycle so that TCLK
 * does not change while the TAP leaves and re-enters Run-Test/Idle.
 */
uint32_t SbwTap::scan(bool ir, unsigned nbits, uint32_t data)
{
	const unsigned head = ir ? 4u : 3u;
	uint32_t tms = ir ? 0b0011u : 0b001u;
	uint32_t tdi = (ir ? 0b1110u : 0b110u) | (tclk_ ? 1u : 0u);

	for (unsigned k = 0; k < nbits; ++k) {
		if ((data >> (nbits - 1u - k)) & 1u) {
			tdi |= 1u << (head + k);
		}
	}
	tms |= 1u << (head + nbits - 1u); /* last data bit: Exit1 */
	tms |= 1u << (head + nbits);      /* Update */
	tdi |= 1u << (head + nbits);
	if (tclk_) {
		tdi |= 1u << (head + nbits + 1u); /* Run-Test/Idle: TDI = TCLK */
	}

	const uint32_t tdo = port_.cycles(tms, tdi, head + nbits + 2u);

	uint32_t out = 0;
	for (unsigned k = 0; k < nbits; ++k) {
		out = (out << 1) | ((tdo >> (head + k)) & 1u);
	}
	return out;
}

uint8_t SbwTap::ir_shift(uint8_t ir)
{
	return static_cast<uint8_t>(scan(true, 8, ir));
}

uint16_t SbwTap::dr_shift16(uint16_t value)
{
	return static_cast<uint16_t>(scan(false, 16, value));
}

uint32_t SbwTap::dr_shift20(uint32_t value)
{
	const uint32_t v = scan(false, 20, value & 0xFFFFFu);
	/* AllShifts, F_ADDR: de-scramble the 20-bit result. */
	return ((v << 16) + (v >> 4)) & 0xFFFFFu;
}

/* SetTCLK_sbw / ClrTCLK_sbw: one Run-Test/Idle cycle whose TDI slot carries
 * the new TCLK level; the TMS slot uses TMSLDH when TCLK is currently high. */
void SbwTap::set_tclk()
{
	port_.tclk_cycle(tclk_, true);
	tclk_ = true;
}

void SbwTap::clr_tclk()
{
	port_.tclk_cycle(tclk_, false);
	tclk_ = false;
}
```

```cpp
		case msp430::kIrCntrlSigCapture:
			return pop(cntrl_sig_script, cntrl_sig);
		case msp430::kIrCoreipId:
			return core_id;
		case msp430::kIrDataQuick:
			return pop(quick_words, 0xFFFF);
		case msp430::kIrJmbExchange:
			return pop(jmb_words, jmb_default);
		case msp430::kIrDataToAddr:
			mem_writes.push_back({addr_, value});
			return 0;
		default:
			return 0;
		}
	}

	uint32_t dr_shift20(uint32_t value) override
	{
		log.push_back(fmt("dr20:%05x", value));
		if (ir_ == msp430::kIrAddr16Bit) {
			addr_ = value;
		}
		return ir_ == msp430::kIrDeviceId ? device_id_ptr : 0;
	}

	void set_tclk() override { log.push_back("tclk:1"); }
	void clr_tclk() override { log.push_back("tclk:0"); }
	void delay_ms(uint32_t ms) override { log.push_back("delay:" + std::to_string(ms)); }
	uint32_t millis() override
	{
		millis_now += millis_step;
		return millis_now;
	}

private:
	static std::string fmt(const char *f, unsigned v)
	{
		char buf[32];
		std::snprintf(buf, sizeof(buf), f, v);
		return buf;
	}
	static uint16_t pop(std::deque<uint16_t> &q, uint16_t fallback)
	{
		if (q.empty()) {
			return fallback;
		}
		const uint16_t v = q.front();
		q.pop_front();
		return v;
	}

	uint8_t ir_ = 0;
	uint32_t addr_ = 0;
};
```

```cpp
/* "Check Init State": the CPU is under JTAG control and synchronized. */
bool Cpuxv2::in_full_emulation()
{
	tap_.ir_shift(kIrCntrlSigCapture);
	return (tap_.dr_shift16(0) & 0x0301) != 0;
}

/* WriteMem_430Xv2(F_WORD, addr, data) */
bool Cpuxv2::write_word(uint32_t addr, uint16_t data)
{
	if (!in_full_emulation()) {
		return false;
	}
	tap_.clr_tclk();
	tap_.ir_shift(kIrCntrlSig16Bit);
	tap_.dr_shift16(0x0500);
	tap_.ir_shift(kIrAddr16Bit);
	tap_.dr_shift20(addr);
	tap_.set_tclk();
	/* New style: only apply data during the clock high phase */
	tap_.ir_shift(kIrDataToAddr);
	tap_.dr_shift16(data);
	tap_.clr_tclk();
	tap_.ir_shift(kIrCntrlSig16Bit);
	tap_.dr_shift16(0x0501);
	tap_.set_tclk();
	/* one more cycle, so the CPU is driving the correct MAB */
	tap_.clr_tclk();
	tap_.set_tclk();
	return true;
}

/* SetPC_430Xv2(addr): feed "MOVA #imm20, PC" to the CPU. */
bool Cpuxv2::set_pc(uint32_t addr)
{
	const uint16_t mova = static_cast<uint16_t>(0x0080u | ((addr >> 8) & 0x0F00u));
	const uint16_t pc_low = static_cast<uint16_t>(addr & 0xFFFFu);

	if (!in_full_emulation()) {
		return false;
	}
	tap_.clr_tclk();
	/* take over bus control during the clock low phase */
	tap_.ir_shift(kIrData16Bit);
	tap_.set_tclk();
	tap_.dr_shift16(mova);
	tap_.clr_tclk();
	tap_.ir_shift(kIrCntrlSig16Bit);
	tap_.dr_shift16(0x1400);
	tap_.ir_shift(kIrData16Bit);
	tap_.clr_tclk();
	tap_.set_tclk();
	tap_.dr_shift16(pc_low);
	tap_.clr_tclk();
	tap_.set_tclk();
	tap_.dr_shift16(0x4303); /* NOP */
	tap_.clr_tclk();
	tap_.ir_shift(kIrAddrCapture);
	tap_.dr_shift20(0x00000);
	return true;
}

/* WriteMemQuick_430Xv2 */
Status Cpuxv2::write_mem(uint32_t addr, size_t nwords, const uint8_t *src)
{
	for (size_t i = 0; i < nwords; ++i) {
		const uint16_t word = static_cast<uint16_t>(src[2 * i] | (src[2 * i + 1] << 8));
		if (!write_word(addr + 2u * static_cast<uint32_t>(i), word)) {
			return Status::TargetError;
		}
	}
	return Status::Ok;
}

/* ReadMemQuick_430Xv2 (JTAG ID 0x91 path) */
Status Cpuxv2::read_mem(uint32_t addr, size_t nwords, uint8_t *dst)
{
	if (!set_pc(addr)) {
		return Status::TargetError;
	}
	tap_.set_tclk();
	tap_.ir_shift(kIrCntrlSig16Bit);
	tap_.dr_shift16(0x0501);
	tap_.ir_shift(kIrAddrCapture);
	tap_.ir_shift(kIrDataQuick);
	for (size_t i = 0; i < nwords; ++i) {
		tap_.set_tclk();
		tap_.clr_tclk();
		const uint16_t word = tap_.dr_shift16(0);
		dst[2 * i] = static_cast<uint8_t>(word);
		dst[2 * i + 1] = static_cast<uint8_t>(word >> 8);
	}
	tap_.set_tclk();
	return Status::Ok;
}

} // namespace msp430
```

```cpp
bool Cpuxv2::is_locked()
{
	for (int i = 0; i < 3; ++i) { /* the first trial could be wrong */
		tap_.ir_shift(kIrCntrlSigCapture);
		if (tap_.dr_shift16(0xAAAA) == 0x5555) {

/* ExecutePOR_430Xv2 */
bool Cpuxv2::execute_por()
{
	tap_.ir_shift(kIrCntrlSigCapture);
	/* provide one clock cycle to empty the pipe */
	tap_.clr_tclk();
	tap_.set_tclk();
	/* release CPUSUSP and apply POR, then release POR again */
	tap_.ir_shift(kIrCntrlSig16Bit);
	tap_.dr_shift16(0x0C01);
	tap_.dr_shift16(0x0401);
	/* three cycles, plus two to release the CPU-internal POR delay signals */
	for (int i = 0; i < 5; ++i) {
		tap_.clr_tclk();
		tap_.set_tclk();
	}
	/* set CPUSUSP again and provide one more clock */
	tap_.ir_shift(kIrCntrlSig16Bit);
	tap_.dr_shift16(0x0501);
	tap_.clr_tclk();
	tap_.set_tclk();
	/* the CPU is now in full-emulation state: hold the watchdog */
	if (!write_word(kWdtCtl, kWdtHold)) {
		return false;
	}
	return in_full_emulation();
}

/* SyncJtag_AssertPor */
bool Cpuxv2::sync_por()
{
	tap_.ir_shift(kIrCntrlSig16Bit);
	tap_.dr_shift16(0x1501); /* JTAG mode + read */
	if (tap_.ir_shift(kIrCntrlSigCapture) != kJtagId91) {
		return false;
	}
	int polls = 0;
	while ((tap_.dr_shift16(0) & 0x0200) == 0) { /* wait for sync */
		if (++polls >= kSyncPolls) {
			return false;
		}
	}
	return execute_por();
}

		if (tap_.millis() - start >= kJmbInTimeoutMs) {
			return false;
		}

	tap_.dr_shift16(kJmbInReq);
	tap_.dr_shift16(value);
	return true;
}

/* GetDevice_430Xv2 = GetCoreID (one attempt) + IsLockKeyProgrammed +
 * GetCoreipIdXv2 + SyncJtag_AssertPor + read of the device ID. */
Status Cpuxv2::connect(EntryMode mode, uint32_t slot_hz, Identity &id)
{
	id = Identity{};
	tap_.set_speed(slot_hz);
	if (!tap_.open()) {
		return Status::Busy;
	}

	if (mode == EntryMode::Normal) {
		tap_.enter(Entry::RstHigh);
		id.jtag_id = tap_.ir_shift(kIrCntrlSigCapture);
	} else {
		/* magicPattern(): enter with RST low, tell the boot code through
		 * the mailbox not to start the user program, enter again. */
		tap_.enter(Entry::RstLow);
		if (jmb_write16(kStopDevice)) {
			tap_.enter(Entry::RstHigh);
			id.jtag_id = tap_.ir_shift(kIrCntrlSigCapture);
			if (id.jtag_id == kJtagId91) {
				/* device was in LPMx.5: reset the JTAG pin I/O lock */
				tap_.ir_shift(kIrTest3vReg);
				tap_.dr_shift16(0x4020);
			}
		}
	}
	if (id.jtag_id != kJtagId91) {
		tap_.close();
		return Status::NoTarget;
	}
	if (is_locked()) {
		tap_.close();
		return Status::Locked;
	}

	/* GetCoreipIdXv2 */
	tap_.ir_shift(kIrCoreipId);
	id.core_id = tap_.dr_shift16(0);
	tap_.ir_shift(kIrDeviceId);
	id.device_id_ptr = tap_.dr_shift20(0);

	uint8_t raw[2] = {};
	if (id.core_id == 0 || !sync_por() ||
	    read_mem(id.device_id_ptr + 4u, 1, raw) != Status::Ok) {
		tap_.close();
		return Status::TargetError;
	}
	id.device_id = static_cast<uint16_t>(raw[0] | (raw[1] << 8));
	return Status::Ok;
}

/* ReleaseDevice_430Xv2(V_RESET), then release the pins. */
void Cpuxv2::disconnect()
{
	tap_.ir_shift(kIrCntrlSig16Bit);
	tap_.dr_shift16(0x0C01); /* perform a reset */
	tap_.dr_shift16(0x0401);
	tap_.ir_shift(kIrCntrlSigRelease);
	tap_.close();
}
```

```cpp
{
	if (!set_pc(addr)) {
		return false;
	}
	tap_.set_tclk();
	tap_.ir_shift(kIrCntrlSig16Bit);
	tap_.dr_shift16(0x0401);

	tap_.ir_shift(kIrCntrlSigRelease);

/* i_ReadJmbOut */
bool Cpuxv2::jmb_read32(uint32_t &value)
{
	tap_.ir_shift(kIrJmbExchange);
	if ((tap_.dr_shift16(0) & kJmbOut1Rdy) == 0) {
		return false; /* nothing new */
	}
	tap_.dr_shift16(kJmb32Bit | kJmbOutReq);
	const uint16_t low = tap_.dr_shift16(0);
	const uint16_t high = tap_.dr_shift16(0);
	value = (static_cast<uint32_t>(high) << 16) | low;
	return true;
}

bool Cpuxv2::jmb_wait(uint32_t expected, uint32_t timeout_ms)
{
	const uint32_t start = tap_.millis();
	for (;;) {
		uint32_t value = 0;
		if (jmb_read32(value) && value == expected) {
			return true;
		}
		if (tap_.millis() - start >= timeout_ms) {
			return false;
		}
	}
}

/* Load a funclet into RAM, replacing words 2..(2 + nparams - 1) with the
 * parameters, and start it at its entry offset (word 0). */
bool Cpuxv2::start_funclet(const uint16_t *code, size_t nwords, uint32_t ram_addr,
			   const uint16_t *params, size_t nparams)
{
	funclet_ram_ = ram_addr;
	funclet_words_ = nwords;
	for (size_t i = 0; i < nwords; ++i) {
		const uint16_t word = (i >= 2 && i < 2 + nparams) ? params[i - 2] : code[i];
		if (!write_word(ram_addr + 2u * static_cast<uint32_t>(i), word)) {
			return false;
		}
	}
	return release_to(ram_addr + code[0]);
}

/* Take control back (SyncJtag_AssertPor) and overwrite the funclet with
 * JMP $, as TI does after every funclet run. */
bool Cpuxv2::funclet_cleanup()
{
	const bool ok = sync_por();
	for (size_t i = 0; i < funclet_words_; ++i) {
		write_word(funclet_ram_ + 2u * static_cast<uint32_t>(i), kJmpSelf);
	}
	funclet_words_ = 0;
	return ok;
}

/* EraseFLASH_430Xv2 */
Status Cpuxv2::erase(EraseMode mode, uint32_t addr, uint32_t ram_addr)
{
	uint16_t fctl1 = 0;
	switch (mode) {
	case EraseMode::Segment: fctl1 = 0xA502; break;
	case EraseMode::Bank:    fctl1 = 0xA504; break;
	case EraseMode::Main:    fctl1 = 0xA506; break;
	default:
		return Status::BadArg;
	}
	const uint16_t params[] = {static_cast<uint16_t>(addr),
				   static_cast<uint16_t>(addr >> 16), fctl1, kInfoALocked};

	if (!start_funclet(kFlashEraseFunclet, kFlashEraseWords, ram_addr, params, 4)) {
		funclet_cleanup();
		return Status::TargetError;
	}
	const bool done = jmb_wait(kFuncletDone, kEraseTimeoutMs);
	const bool clean = funclet_cleanup();
	if (!done) {
		return Status::Timeout;
	}
	return clean ? Status::Ok : Status::TargetError;
}

/* WriteFLASH_430Xv2, part 1: load and start the funclet, wait until it asks
 * for data. */
Status Cpuxv2::flash_begin(uint32_t addr, uint32_t nwords, uint32_t ram_addr)
{
	const uint16_t params[] = {static_cast<uint16_t>(addr),
				   static_cast<uint16_t>(addr >> 16),
				   static_cast<uint16_t>(nwords),
				   static_cast<uint16_t>(nwords >> 16), kInfoALocked};

	if (!start_funclet(kFlashWriteFunclet, kFlashWriteWords, ram_addr, params, 5)) {
		funclet_cleanup();
		return Status::TargetError;
	}
	if (!jmb_wait(kFuncletReady, kReadyTimeoutMs)) {
		funclet_cleanup();
		return Status::Timeout;
	}
	return Status::Ok;
}

/* WriteFLASH_430Xv2, part 2: feed words through the mailbox. */
Status Cpuxv2::flash_data(size_t nwords, const uint8_t *src)
{
	for (size_t i = 0; i < nwords; ++i) {
		const uint16_t word = static_cast<uint16_t>(src[2 * i] | (src[2 * i + 1] << 8));
		if (!jmb_write16(word)) {
			funclet_cleanup();
			return Status::Timeout;
		}
	}
	return Status::Ok;
}

/* WriteFLASH_430Xv2, part 3: wait for completion (only if every announced
 * word was sent), then clean up. */
Status Cpuxv2::flash_end(bool complete)
{
	const bool done = !complete || jmb_wait(kFuncletDone, kWriteDoneTimeoutMs);
	const bool clean = funclet_cleanup();
	if (!done) {
		return Status::Timeout;
	}
	return clean ? Status::Ok : Status::TargetError;
}
```

```cpp
 * Never reads outside the request nor writes outside the response; malformed
 * input yields an error status.

#include <cstddef>
#include <cstdint>
#include <span>

#include "msp430/cpuxv2.hpp"
#include "msp430/protocol.hpp"

namespace msp430 {

class Session {
public:
	/* max_data_bytes: largest data payload of one command, in either
	 * direction (the transport packet size minus the headers). */
	Session(Cpuxv2 &cpu, uint16_t max_data_bytes)
		: cpu_(cpu), max_data_bytes_(max_data_bytes)
	{
	}

	/* `request` starts at the vendor command ID. Returns the response
```

```cpp
#include "msp430/session.hpp"

namespace msp430 {

namespace {

uint16_t get16(std::span<const uint8_t> b, size_t off)
{
	return static_cast<uint16_t>(b[off] | (b[off + 1] << 8));
}

uint32_t get32(std::span<const uint8_t> b, size_t off)
{
	return static_cast<uint32_t>(b[off]) | (static_cast<uint32_t>(b[off + 1]) << 8) |
	       (static_cast<uint32_t>(b[off + 2]) << 16) |
	       (static_cast<uint32_t>(b[off + 3]) << 24);
}

void put16(std::span<uint8_t> b, size_t off, uint16_t v)
{
	b[off] = static_cast<uint8_t>(v);
	b[off + 1] = static_cast<uint8_t>(v >> 8);
}

void put32(std::span<uint8_t> b, size_t off, uint32_t v)
{
	put16(b, off, static_cast<uint16_t>(v));
	put16(b, off + 2, static_cast<uint16_t>(v >> 16));
}

/* Even address, and [addr, addr + 2 * nwords) inside the 20-bit space. */
bool range_ok(uint32_t addr, uint64_t nwords)
{
	return (addr & 1u) == 0 && addr < kAddressSpace &&
	       addr + 2u * nwords <= kAddressSpace;
}

} // namespace

size_t Session::handle(std::span<const uint8_t> request, std::span<uint8_t> response)
{
	if (request.empty() || request[0] != kVendorCmd || response.size() < 2) {
		return 0;
	}
	response[0] = kVendorCmd;
	if (request.size() < 2) {
		response[1] = static_cast<uint8_t>(Status::BadArg);
		return 2;
	}

	const In args = request.subspan(2);
	const Out out = response.subspan(2);
	size_t n = 0;
	Status st = Status::UnknownOp;

	switch (static_cast<Op>(request[1])) {
	case Op::Info:
		st = op_info(out, n);
		break;
	case Op::Connect:
		st = op_connect(args, out, n);
		break;
	case Op::Disconnect:
		st = op_disconnect();
		break;
	case Op::ReadMem:
		st = op_read_mem(args, out, n);
		break;
	case Op::WriteMem:
		st = op_write_mem(args);
		break;
	case Op::Erase:
		st = op_erase(args);
		break;
	case Op::FlashBegin:
		st = op_flash_begin(args);
		break;
	case Op::FlashData:
		st = op_flash_data(args);
		break;
	case Op::FlashEnd:
		st = op_flash_end();
		break;
	default:
		break;
	}

	response[1] = static_cast<uint8_t>(st);
	return 2 + n;
}

void Session::abort()
{
	if (state_ == State::Flashing) {
		cpu_.flash_end(false);
	}
	if (state_ != State::Idle) {
		cpu_.disconnect();
	}
	state_ = State::Idle;
	flash_remaining_ = 0;
}

Status Session::op_info(Out out, size_t &n)
{
	if (out.size() < 8) {
		return Status::BadArg;
	}
	out[0] = kProtocolVersion;
	out[1] = static_cast<uint8_t>(state_);
	put16(out, 2, max_data_bytes_);
	put32(out, 4, kFeatureCpuxv2Flash);
	n = 8;
	return Status::Ok;
}

Status Session::op_connect(In args, Out out, size_t &n)
{
	if (args.size() < 3 || out.size() < 9) {
		return Status::BadArg;
	}
	const uint16_t speed_khz = get16(args, 0);
	const uint8_t mode = args[2];
	if (speed_khz < kMinSpeedKhz || speed_khz > kMaxSpeedKhz || mode > 1) {
		return Status::BadArg;
	}

	abort(); /* a new CONNECT always starts from a clean entry */

	Identity id;
	const Status st = cpu_.connect(static_cast<EntryMode>(mode), speed_khz * 1000u, id);
	if (st == Status::Ok) {
		state_ = State::Connected;
		out[0] = id.jtag_id;
		put16(out, 1, id.core_id);
		put32(out, 3, id.device_id_ptr);
		put16(out, 7, id.device_id);
		n = 9;
	} else if (st == Status::NoTarget) {
		out[0] = id.jtag_id;
		n = 1;
	}
	return st;
}

Status Session::op_disconnect()
{
	if (state_ == State::Idle) {
		return Status::BadState;
	}
	abort();
	return Status::Ok;
}

Status Session::op_read_mem(In args, Out out, size_t &n)
{
	if (state_ != State::Connected) {
		return Status::BadState;
	}
	if (args.size() < 6) {
		return Status::BadArg;
	}
	const uint32_t addr = get32(args, 0);
	const size_t nwords = get16(args, 4);
	const size_t nbytes = 2 * nwords;
	if (nwords == 0 || !range_ok(addr, nwords) || nbytes > max_data_bytes_ ||
	    nbytes > out.size()) {
		return Status::BadArg;
	}
	const Status st = cpu_.read_mem(addr, nwords, out.data());
	if (st == Status::Ok) {
		n = nbytes;
	}
	return st;
}

Status Session::op_write_mem(In args)
{
	if (state_ != State::Connected) {
		return Status::BadState;
	}
	if (args.size() < 4) {
		return Status::BadArg;
	}
	const uint32_t addr = get32(args, 0);
	const In data = args.subspan(4);
	if (data.empty() || (data.size() & 1u) != 0 || data.size() > max_data_bytes_ ||
	    !range_ok(addr, data.size() / 2)) {
		return Status::BadArg;
	}
	return cpu_.write_mem(addr, data.size() / 2, data.data());
}

Status Session::op_erase(In args)
{
	if (state_ != State::Connected) {
		return Status::BadState;
	}
	if (args.size() < 9) {
		return Status::BadArg;
	}
	const uint8_t mode = args[0];
	const uint32_t addr = get32(args, 1);
	const uint32_t ram = get32(args, 5);
	if (mode > 2 || !range_ok(addr, 1) || !range_ok(ram, 1)) {
		return Status::BadArg;
	}
	return cpu_.erase(static_cast<EraseMode>(mode), addr, ram);
}

Status Session::op_flash_begin(In args)
{
	if (state_ != State::Connected) {
		return Status::BadState;
	}
	if (args.size() < 12) {
		return Status::BadArg;
	}
	const uint32_t addr = get32(args, 0);
	const uint32_t nwords = get32(args, 4);
	const uint32_t ram = get32(args, 8);
	if (nwords == 0 || !range_ok(addr, nwords) || !range_ok(ram, 1)) {
		return Status::BadArg;
	}
	const Status st = cpu_.flash_begin(addr, nwords, ram);
	if (st == Status::Ok) {
		state_ = State::Flashing;
		flash_remaining_ = nwords;
	}
	return st;
}

Status Session::op_flash_data(In args)
{
	if (state_ != State::Flashing) {
		return Status::BadState;
	}
	const size_t nwords = args.size() / 2;
	if (args.empty() || (args.size() & 1u) != 0 || args.size() > max_data_bytes_ ||
	    nwords > flash_remaining_) {
		/* The funclet cannot be resynchronized: abandon the write. */
		cpu_.flash_end(false);
		state_ = State::Connected;
		return Status::BadArg;
	}
	const Status st = cpu_.flash_data(nwords, args.data());
	if (st == Status::Ok) {
		flash_remaining_ -= static_cast<uint32_t>(nwords);
	} else {
		state_ = State::Connected; /* Cpuxv2 already cleaned up */
	}
	return st;
}

Status Session::op_flash_end()
{
	if (state_ != State::Flashing) {
		return Status::BadState;
	}
	const bool complete = flash_remaining_ == 0;
	const Status st = cpu_.flash_end(complete);
	state_ = State::Connected;
	if (!complete && st == Status::Ok) {
		return Status::BadState;
	}
	return st;
}

} // namespace msp430
```

### Task 9: PIO program and word packing

The PIO state machine takes one TX word per command. A word holds 1 to 9 JTAG cycles; a 32-cycle call needs four words, which is exactly the FIFO depth.

```
bits 3:0   number of cycles - 1
then per cycle, 3 bits:  TMS, MID, TDI
```

`MID` is the level on SBWTDIO during the low phase of the TMS slot. It equals TMS, except for TI's TMSLDH (TMS = 0, MID = 1).

```c
/*
 * TX word layout of the SBW PIO program (drivers/sbw_pio/sbw.pio).
 * Pure C with no dependencies so it can be unit-tested on the host.
 */
#ifndef SBW_PACK_H_
#define SBW_PACK_H_

#include <stdint.h>

/* Cycles carried by one TX word: 4 count bits + 9 * 3 cycle bits = 31. */
#define SBW_CYCLES_PER_WORD 9U
/* Cycles per driver call: 4 words fill the TX FIFO, 4 results the RX FIFO. */
#define SBW_MAX_CYCLES 32U

/* Pack cycles [first, first + n) of the per-cycle bit vectors into one word.
 * n must be 1..SBW_CYCLES_PER_WORD. */
static inline uint32_t sbw_pack_word(uint32_t tms, uint32_t mid, uint32_t tdi,
				     unsigned int first, unsigned int n)
{
	uint32_t word = (n - 1U) & 0xFU;

	for (unsigned int i = 0; i < n; i++) {
		const unsigned int c = first + i;
		const uint32_t bits = ((tms >> c) & 1U) | (((mid >> c) & 1U) << 1) |
				      (((tdi >> c) & 1U) << 2);

		word |= bits << (4U + 3U * i);
	}
	return word;
}

#endif /* SBW_PACK_H_ */
```

```
;
; Spy-Bi-Wire transport for MSP430 targets. Driver: drivers/sbw_pio/sbw_pio.c.
;
; One TX word is one command of 1..9 JTAG cycles, shifted out LSB first:
;   bits 3:0   number of cycles - 1
;   then 3 bits per cycle: TMS, MID, TDI   (see sbw_pack.h)
; MID is the level on SBWTDIO during the low phase of the TMS slot. It equals
; TMS, except for TI's "TMSLDH" (TMS = 0, MID = 1), which keeps TCLK high.
;
; One RX word per command: the TDO samples, shifted in from the MSB side.
;
; Waveform, after the TMSH/TMSL/TMSLDH/TDIH/TDIL/TDO_RD macros in TI slau320
; LowLevelFunc430Xv2.h. One slot is 8 state-machine ticks, 4 high and 4 low.
; The machine only ever waits (pull, push) with SBWTCK high: a low phase
; longer than about 7 us resets the target's SBW logic.
;
; Pins: side-set = SBWTCK; out and set = SBWTDIO; in = SBWTDIO, or the
; separate input pin on boards that have one.

.program sbw
.side_set 1 opt

.wrap_target
public entry:
    pull block          side 1      ; wait for a command with the clock high
    out x, 4                        ; cycles - 1
cycle:
    ; TMS slot
    out pins, 1         side 1 [3]  ; TMS on the line, clock high
    nop                 side 0 [2]  ; clock low
    out pins, 1         side 0      ; MID: line level before the rising edge
    ; TDI slot
    nop                 side 1      ; rising edge, line still holds MID
    out pins, 1                [2]  ; TDI on the line, clock high
    nop                 side 0 [3]  ; clock low
    ; TDO slot
    nop                 side 1      ; rising edge, line still holds TDI
    set pindirs, 0             [2]  ; release the line, clock high
    nop                 side 0 [2]  ; clock low, the target drives TDO
    in pins, 1          side 0      ; sample at the end of the low phase
    nop                 side 1 [1]  ; rising edge, the target releases the line
    set pindirs, 1                  ; drive the line again (last TDI level)
    jmp x-- cycle
    push block                      ; one RX word per command, clock high
.wrap
```

`drivers/sbw_pio/sbw_pio.c`:

```c
/*
 * PIO Spy-Bi-Wire transport for RP2040/RP2350.
 *
 * The state machine (sbw.pio) runs only while cycles are being clocked. The
 * entry sequence needs static pin levels; those are produced by executing
 * single instructions on the stopped machine, the same mechanism the pico-sdk
 * uses in pio_sm_set_consecutive_pindirs().
 *
 * SPDX-License-Identifier: MIT
 */
#define DT_DRV_COMPAT debugprobe_sbw_pio

#include <zephyr/device.h>
#include <zephyr/drivers/misc/pio_rpi_pico/pio_rpi_pico.h>
#include <zephyr/drivers/pinctrl.h>
#include <zephyr/irq.h>
#include <zephyr/kernel.h>
#include <zephyr/logging/log.h>
#include <zephyr/sys/util.h>

#include <hardware/pio.h>

#include "sbw_pack.h"
#include "sbw_pio.h"
#include "sbw_pio_program.h"

LOG_MODULE_REGISTER(sbw_pio, LOG_LEVEL_INF);

/* clk_sys from devicetree, as in drivers/dp_pio/swdp_pio.c. */
#define CLK_SYS_HZ DT_PROP(DT_NODELABEL(clk_sys), clock_frequency)

/* sbw.pio spends 8 state-machine ticks per slot. */
#define SBW_TICKS_PER_SLOT 8U
#define SBW_DEFAULT_SLOT_HZ 250000U

struct sbw_pio_config {
	const struct device *piodev;
	const struct pinctrl_dev_config *pcfg;
	uint8_t tck_pin;
	uint8_t tdio_pin;
	uint8_t tdi_in_pin; /* == tdio_pin unless the board has a separate input */
};

struct sbw_pio_data {
	size_t sm;
	uint offset;
	bool running;
};

static inline PIO sbw_pio(const struct device *dev)
{
	const struct sbw_pio_config *cfg = dev->config;

	return pio_rpi_pico_get_pio(cfg->piodev);
}

static void sbw_stop(const struct device *dev)
{
	struct sbw_pio_data *d = dev->data;

	if (d->running) {
		/* The machine is parked at `pull block side 1`: clock high. */
		pio_sm_set_enabled(sbw_pio(dev), d->sm, false);
		d->running = false;
	}
}

static void sbw_start(const struct device *dev)
{
	struct sbw_pio_data *d = dev->data;
	PIO pio = sbw_pio(dev);

	if (!d->running) {
		pio_sm_clear_fifos(pio, d->sm);
		pio_sm_restart(pio, d->sm);
		pio_sm_exec(pio, d->sm, pio_encode_jmp(d->offset + sbw_offset_entry));
		pio_sm_set_enabled(pio, d->sm, true);
		d->running = true;
	}
}

static void sbw_exec_tck(const struct device *dev, bool level)
{
	struct sbw_pio_data *d = dev->data;

	pio_sm_exec(sbw_pio(dev), d->sm,
		    pio_encode_nop() | pio_encode_sideset_opt(1, level ? 1U : 0U));
}

int sbw_pio_acquire(const struct device *dev)
{
	const struct sbw_pio_config *cfg = dev->config;
	struct sbw_pio_data *d = dev->data;
	PIO pio = sbw_pio(dev);
	int ret;

	sbw_stop(dev);

	/* The SWD driver may have routed the pins to PIO0 since the last
	 * session; take them back. */
	ret = pinctrl_apply_state(cfg->pcfg, PINCTRL_STATE_DEFAULT);
	if (ret < 0) {
		return ret;
	}

	/* Levels first, then directions: SBWTCK low, SBWTDIO high (TI
	 * DrvSignals). */
	sbw_exec_tck(dev, false);
	pio_sm_exec(pio, d->sm, pio_encode_set(pio_pins, 1));
	pio_sm_set_consecutive_pindirs(pio, d->sm, cfg->tck_pin, 1, true);
	pio_sm_set_consecutive_pindirs(pio, d->sm, cfg->tdio_pin, 1, true);

	return 0;
}

void sbw_pio_release(const struct device *dev)
{
	const struct sbw_pio_config *cfg = dev->config;
	struct sbw_pio_data *d = dev->data;
	PIO pio = sbw_pio(dev);

	sbw_stop(dev);
	pio_sm_set_consecutive_pindirs(pio, d->sm, cfg->tdio_pin, 1, false);
	pio_sm_set_consecutive_pindirs(pio, d->sm, cfg->tck_pin, 1, false);
}

void sbw_pio_set_clock(const struct device *dev, uint32_t slot_hz)
{
	struct sbw_pio_data *d = dev->data;
	uint64_t tick_hz;
	uint64_t div256;

	if (slot_hz == 0U) {
		slot_hz = SBW_DEFAULT_SLOT_HZ;
	}
	tick_hz = (uint64_t)slot_hz * SBW_TICKS_PER_SLOT;
	/* Divider in 1/256 steps, rounded up so the clock is never faster
	 * than requested. */
	div256 = ((uint64_t)CLK_SYS_HZ * 256U + tick_hz - 1U) / tick_hz;
	div256 = CLAMP(div256, 256U, (65535U * 256U) + 255U);

	pio_sm_set_clkdiv_int_frac(sbw_pio(dev), d->sm, (uint16_t)(div256 >> 8),
				   (uint8_t)(div256 & 0xFFU));
}

void sbw_pio_set_tck(const struct device *dev, bool level)
{
	sbw_stop(dev);
	sbw_exec_tck(dev, level);
}

void sbw_pio_set_tdio(const struct device *dev, bool level)
{
	struct sbw_pio_data *d = dev->data;

	sbw_stop(dev);
	pio_sm_exec(sbw_pio(dev), d->sm, pio_encode_set(pio_pins, level ? 1U : 0U));
}

void sbw_pio_tck_pulse(const struct device *dev)
{
	unsigned int key;

	sbw_stop(dev);
	/* TI: _DINT(); ClrTST(); usDelay(1); SetTST(); _EINT(); -- the low time
	 * must stay well under 7 us. */
	key = irq_lock();
	sbw_exec_tck(dev, false);
	k_busy_wait(1);
	sbw_exec_tck(dev, true);
	irq_unlock(key);
}

uint32_t sbw_pio_cycles(const struct device *dev, uint32_t tms, uint32_t mid,
			uint32_t tdi, unsigned int count)
{
	struct sbw_pio_data *d = dev->data;
	PIO pio = sbw_pio(dev);
	unsigned int len[SBW_MAX_CYCLES / SBW_CYCLES_PER_WORD + 1U];
	unsigned int words = 0;
	unsigned int first = 0;
	uint32_t tdo = 0;

	if (count == 0U || count > SBW_MAX_CYCLES) {
		return 0;
	}

	sbw_start(dev);

	/* At most 4 words: they fit the TX FIFO, their results the RX FIFO. */
	while (first < count) {
		const unsigned int n = MIN(count - first, SBW_CYCLES_PER_WORD);

		pio_sm_put_blocking(pio, d->sm, sbw_pack_word(tms, mid, tdi, first, n));
		len[words++] = n;
		first += n;
	}

	first = 0;
	for (unsigned int i = 0; i < words; i++) {
		/* The machine shifts samples in from the MSB side. */
		const uint32_t v = pio_sm_get_blocking(pio, d->sm) >> (32U - len[i]);

		tdo |= v << first;
		first += len[i];
	}

	return tdo;
}

static int sbw_pio_init(const struct device *dev)
{
	const struct sbw_pio_config *cfg = dev->config;
	struct sbw_pio_data *d = dev->data;
	pio_sm_config c;
	PIO pio;
	int ret;

	if (!device_is_ready(cfg->piodev)) {
		return -ENODEV;
	}
	pio = pio_rpi_pico_get_pio(cfg->piodev);

	ret = pio_rpi_pico_allocate_sm(cfg->piodev, &d->sm);
	if (ret < 0) {
		return ret;
	}
	d->offset = pio_add_program(pio, RPI_PICO_PIO_GET_PROGRAM(sbw));

	c = pio_get_default_sm_config();
	sm_config_set_wrap(&c, d->offset + RPI_PICO_PIO_GET_WRAP_TARGET(sbw),
			   d->offset + RPI_PICO_PIO_GET_WRAP(sbw));
	/* `.side_set 1 opt`: one data bit plus the enable bit. */
	sm_config_set_sideset(&c, 2, true, false);
	sm_config_set_sideset_pins(&c, cfg->tck_pin);
	sm_config_set_out_pins(&c, cfg->tdio_pin, 1);
	sm_config_set_set_pins(&c, cfg->tdio_pin, 1);
	sm_config_set_in_pins(&c, cfg->tdi_in_pin);
	sm_config_set_out_shift(&c, true, false, 32);
	sm_config_set_in_shift(&c, true, false, 32);
	pio_sm_init(pio, d->sm, d->offset + sbw_offset_entry, &c);

	sbw_pio_set_clock(dev, SBW_DEFAULT_SLOT_HZ);

	/* Idle state from boot: both pins inputs, pulls from pinctrl (pull-up
	 * on SBWTDIO so the probe does not fight the target's RST pull-up,
	 * pull-down on SBWTCK). */
	pio_sm_set_consecutive_pindirs(pio, d->sm, cfg->tdio_pin, 1, false);
	pio_sm_set_consecutive_pindirs(pio, d->sm, cfg->tck_pin, 1, false);

	return pinctrl_apply_state(cfg->pcfg, PINCTRL_STATE_DEFAULT);
}

#define SBW_PIO_DEFINE(n)							\
	PINCTRL_DT_INST_DEFINE(n);						\

		.piodev = DEVICE_DT_GET(DT_INST_PHANDLE(n, piodev)),		\
		.pcfg = PINCTRL_DT_INST_DEV_CONFIG_GET(n),			\
		.tck_pin = DT_INST_PROP(n, tck_pin),				\
		.tdio_pin = DT_INST_PROP(n, tdio_pin),				\
		.tdi_in_pin = DT_INST_PROP_OR(n, tdi_in_pin,			\
					      DT_INST_PROP(n, tdio_pin)),	\
	};									\
	static struct sbw_pio_data sbw_pio_data_##n;				\

			      POST_KERNEL, CONFIG_KERNEL_INIT_PRIORITY_DEVICE,	\
			      NULL);

DT_INST_FOREACH_STATUS_OKAY(SBW_PIO_DEFINE)
```

```cpp
#pragma once
/* Who drives the two debug pins: the SWD port (PIO0) or the SBW port (PIO1).
 * Pure C++ (host-tested). Every call comes from the DAP request thread, so
 * there is no locking.
 */
namespace probe::pin_owner {

/* SWD is taking the pins. An open SBW session is force-closed first, so a
 * crashed SBW tool cannot lock out an SWD debugger. */
void swd_connect();
void swd_disconnect();

/* SBW asks for the pins. Refused while SWD is connected. */
bool sbw_claim();
void sbw_release();

/* Hook that closes an open SBW session; installed by the MSP430 backend. */
void set_sbw_force_close(void (*hook)());

} // namespace probe::pin_owner
```

`src/pin_owner.cpp`:

```cpp
#include "pin_owner.hpp"

namespace probe::pin_owner {

namespace {

enum class Owner { None, Swd, Sbw };

Owner g_owner = Owner::None;
void (*g_force_close)() = nullptr;

} // namespace

void swd_connect()
{
	if (g_owner == Owner::Sbw && g_force_close != nullptr) {
		g_force_close(); /* releases the pins through sbw_release() */
	}
	g_owner = Owner::Swd;
}

void swd_disconnect()
{
	if (g_owner == Owner::Swd) {
		g_owner = Owner::None;
	}
}

bool sbw_claim()
{
	if (g_owner == Owner::Swd) {
		return false;
	}
	g_owner = Owner::Sbw;
	return true;
}

void sbw_release()
{
	if (g_owner == Owner::Sbw) {
		g_owner = Owner::None;
	}
}

void set_sbw_force_close(void (*hook)())
{
	g_force_close = hook;
}

} // namespace probe::pin_owner
```

```cpp
#include <zephyr/kernel.h>

#include "sbw_pio.h"

bool PioSbwPort::acquire()
{
	if (!device_is_ready(dev_) || !pin_owner::sbw_claim()) {
		return false;
	}
	if (sbw_pio_acquire(dev_) < 0) {
		pin_owner::sbw_release();
		return false;
	}
	return true;
}

{
	/* Also called before acquire() (SbwTap::open). When SWD owns the pins
	 * they are muxed to PIO0, so this only touches PIO1's unused outputs
	 * and sbw_release() is a no-op. */
	if (device_is_ready(dev_)) {
		sbw_pio_release(dev_);
	}
	pin_owner::sbw_release();

}
```

```cpp
#include <zephyr/devicetree.h>

#include "dap/dap_backend.hpp"
#include "dap/interfaces.hpp"
#include "leds.hpp"
#include "msp430/cpuxv2.hpp"
#include "msp430/pio_sbw_port.hpp"
#include "msp430/sbw_tap.hpp"
#include "msp430/session.hpp"
#include "pin_owner.hpp"
#include "usb/dap_class.hpp"

namespace probe::msp430_backend {

namespace {

/* Largest data payload of one command: the DAP packet minus the longest
 * header ([0x90][op] + 4 address bytes), rounded down to leave slack. */
constexpr uint16_t kMaxDataBytes = probe::usb::kDapPacketSize - 8;

PioSbwPort g_port{DEVICE_DT_GET(DT_NODELABEL(sbw_pio))};
msp430::SbwTap g_tap{g_port};
msp430::Cpuxv2 g_cpu{g_tap};
msp430::Session g_session{g_cpu, kMaxDataBytes};
LedHostStatus g_led; /* stateless: drives the DAP-connected LED, if any */

class Handler final : public dap::VendorHandler {
public:
	size_t handle(std::span<const uint8_t> request,
		      std::span<uint8_t> response) override
	{
		const size_t n = g_session.handle(request, response);

		if (n != 0) {
			update_led();
		}
		return n;
	}

	/* Light the DAP-connected LED while an SBW session is open. */
	void update_led()
	{
		const bool open = g_session.state() != msp430::State::Idle;

		if (open != led_on_) {
			led_on_ = open;
			g_led.connected(open);
		}
	}

private:
	bool led_on_ = false;
};

Handler g_handler;

} // namespace

void init()
{
	pin_owner::set_sbw_force_close(abort);
	dap_backend::set_vendor_handler(&g_handler);
}

void abort()
{
	g_session.abort();
	g_handler.update_led();
}

} // namespace probe::msp430_backend
```

```python
"""Firmware image files: Intel HEX and TI-TXT readers, Intel HEX and raw writers."""
from __future__ import annotations

from dataclasses import dataclass


class ImageError(Exception):
    """The image file is malformed."""


@dataclass(frozen=True)
class Segment:
    """A contiguous run of bytes at an absolute address."""

    addr: int
    data: bytes

    @property
    def end(self) -> int:
        return self.addr + len(self.data)


def _segments(byte_map: dict[int, int]) -> list[Segment]:
    """Group an address->byte map into contiguous segments, sorted by address."""
    segs: list[Segment] = []
    start = prev = None
    buf = bytearray()
    for addr in sorted(byte_map):
        if prev is None or addr != prev + 1:
            if buf:
                segs.append(Segment(start, bytes(buf)))
            start, buf = addr, bytearray()
        buf.append(byte_map[addr])
        prev = addr
    if buf:
        segs.append(Segment(start, bytes(buf)))
    return segs


def _store(byte_map: dict[int, int], addr: int, value: int, lineno: int) -> None:
    if addr in byte_map:
        raise ImageError(f"line {lineno}: overlapping data at 0x{addr:05X}")
    byte_map[addr] = value


def parse_ihex(text: str) -> list[Segment]:
    byte_map: dict[int, int] = {}
    base = 0
    eof = False
    for lineno, raw in enumerate(text.splitlines(), 1):
        line = raw.strip()
        if not line:
            continue
        if eof:
            raise ImageError(f"line {lineno}: data after the end-of-file record")
        if not line.startswith(":"):
            raise ImageError(f"line {lineno}: not an Intel HEX record")
        try:
            rec = bytes.fromhex(line[1:])
        except ValueError:
            raise ImageError(f"line {lineno}: not hexadecimal") from None
        if len(rec) < 5 or len(rec) != rec[0] + 5:
            raise ImageError(f"line {lineno}: wrong record length")
        if sum(rec) & 0xFF:
            raise ImageError(f"line {lineno}: bad checksum")
        offset = (rec[1] << 8) | rec[2]
        rtype = rec[3]
        data = rec[4:-1]
        if rtype == 0x00:
            for i, value in enumerate(data):
                _store(byte_map, base + offset + i, value, lineno)
        elif rtype == 0x01:
            eof = True
        elif rtype in (0x02, 0x04):
            if len(data) != 2:
                raise ImageError(f"line {lineno}: wrong record length")
            base = ((data[0] << 8) | data[1]) << (4 if rtype == 0x02 else 16)
        elif rtype in (0x03, 0x05):
            pass  # start address: not used
        else:
            raise ImageError(f"line {lineno}: unsupported record type {rtype:02X}")
    if not eof:
        raise ImageError("missing end-of-file record")
    return _segments(byte_map)


def parse_titxt(text: str) -> list[Segment]:
    byte_map: dict[int, int] = {}
    addr = None
    done = False
    for lineno, raw in enumerate(text.splitlines(), 1):
        line = raw.strip()
        if not line:
            continue
        if done:
            raise ImageError(f"line {lineno}: data after the terminating 'q'")
        try:
            if line.startswith("@"):
                addr = int(line[1:], 16)
            elif line.lower() == "q":
                done = True
            else:
                if addr is None:
                    raise ImageError(f"line {lineno}: data before the first @address")
                for token in line.split():
                    if len(token) != 2:
                        raise ValueError(token)
                    _store(byte_map, addr, int(token, 16), lineno)
                    addr += 1
        except ValueError:
            raise ImageError(f"line {lineno}: not hexadecimal") from None
    if not done:
        raise ImageError("missing terminating 'q'")
    return _segments(byte_map)


def load(path: str) -> list[Segment]:
    """Read an image; the format is detected from the first character."""
    with open(path, "r", errors="replace") as f:
        text = f.read()
    first = text.lstrip()[:1]
    try:
        if first == ":":
            return parse_ihex(text)
        if first == "@":
            return parse_titxt(text)
    except ImageError as e:
        raise ImageError(f"{path}: {e}") from None
    raise ImageError(f"{path}: neither Intel HEX nor TI-TXT (use objcopy -O ihex for ELF files)")


def pad_to_words(segments: list[Segment], fill: int = 0xFF) -> list[Segment]:
    """Make every segment start on an even address and have an even length."""
    byte_map = {s.addr + i: b for s in segments for i, b in enumerate(s.data)}
    for addr in list(byte_map):
        byte_map.setdefault(addr ^ 1, fill)
    return _segments(byte_map)


def _record(rtype: int, offset: int, data: bytes) -> str:
    rec = bytes([len(data), (offset >> 8) & 0xFF, offset & 0xFF, rtype]) + data
    return ":" + (rec + bytes([-sum(rec) & 0xFF])).hex().upper()


def write_ihex(segments: list[Segment]) -> str:
    lines = []
    upper = 0
    for seg in segments:
        for off in range(0, len(seg.data), 16):
            addr = seg.addr + off
            if addr >> 16 != upper:
                upper = addr >> 16
                lines.append(_record(0x04, 0, bytes([upper >> 8, upper & 0xFF])))
            lines.append(_record(0x00, addr & 0xFFFF, seg.data[off:off + 16]))
    lines.append(_record(0x01, 0, b""))
    return "\n".join(lines) + "\n"


def save(path: str, segments: list[Segment]) -> None:
    """Write `.bin` as raw bytes (one segment only), anything else as Intel HEX."""
    if path.lower().endswith(".bin"):
        if len(segments) != 1:
            raise ImageError("a .bin file can hold only one contiguous block")
        with open(path, "wb") as f:
            f.write(segments[0].data)
    else:
        with open(path, "w") as f:
            f.write(write_ihex(segments))
```

```python
"""Stands in for the probe in tests: answers DAP_Disconnect and the SBW vendor
command the way the firmware's msp430::Session does, on top of a flash model."""
import struct

OK, BAD_ARG, BAD_STATE, NO_TARGET, TIMEOUT, UNKNOWN_OP = 0, 1, 2, 4, 7, 8
MAIN = (0x4400, 0x24400)


class FakeFirmware:
    def __init__(self, device_id=0x2955):
        self.device_id = device_id
        self.mem = {}                # address -> byte; missing = erased (0xFF)
        self.state = 0               # 0 idle, 1 connected, 2 flashing
        self.no_target = {}          # entry mode -> NO_TARGET answers still to give
        self.no_target_id = 0xFF
        self.connects = []           # entry modes of every CONNECT
        self.ops = []                # ("erase", mode, addr, ram), ("begin", addr, nwords, ram), ...
        self.fail_flash_after = None # words accepted before FLASH_DATA answers TIMEOUT
        self.stuck = {}              # address -> byte that reads back regardless
        self.has_handler = True
        self.closed = False
        self._flash_addr = 0
        self._remaining = 0
        self._written = 0

    # --- transport interface used by SbwProbe ---
    def transfer(self, request, timeout_ms=3000):
        request = bytes(request)
        assert len(request) % 64 != 0, "request length is a multiple of 64"
        response = self._handle(request)
        assert len(response) % 64 != 0, "response length is a multiple of 64"
        return response

    def close(self):
        self.closed = True

    # --- firmware model ---
    def _handle(self, req):
        if req[0] == 0x03:  # DAP_Disconnect
            self.ops.append(("dap_disconnect",))
            return b"\x03\x00"
        if req[0] != 0x90 or not self.has_handler:
            return req[:1]  # vendor echo
        if len(req) < 2:
            return bytes([0x90, BAD_ARG])
        status, data = self._op(req[1], req[2:])
        return bytes([0x90, status]) + data

    def _op(self, op, a):
        if op == 0:
            return OK, struct.pack("<BBHI", 1, self.state, 1016, 1)
        if op == 1:
            _speed, mode = struct.unpack("<HB", a[:3])
            self.connects.append(mode)
            self.state = 0
            if self.no_target.get(mode, 0) > 0:
                self.no_target[mode] -= 1
                return NO_TARGET, bytes([self.no_target_id])
            self.state = 1
            return OK, struct.pack("<BHIH", 0x91, 0x0106, 0x1A00, self.device_id)
        if op == 2:
            if self.state == 0:
                return BAD_STATE, b""
            self.state = 0
            self.ops.append(("disconnect",))
            return OK, b""
        if op == 3:
            if self.state != 1:
                return BAD_STATE, b""
            addr, n = struct.unpack("<IH", a[:6])
            return OK, bytes(self.stuck.get(x, self.mem.get(x, 0xFF))
                             for x in range(addr, addr + 2 * n))
        if op == 5:
            if self.state != 1:
                return BAD_STATE, b""
            mode, addr, ram = struct.unpack("<BII", a[:9])
            self.ops.append(("erase", mode, addr, ram))
            if mode == 2:
                lo, hi = MAIN
            else:
                size = 512 if addr >= MAIN[0] else 128
                lo = addr - addr % size
                hi = lo + size
            for x in [x for x in self.mem if lo <= x < hi]:
                del self.mem[x]
            return OK, b""
        if op == 6:
            if self.state != 1:
                return BAD_STATE, b""
            addr, nwords, ram = struct.unpack("<III", a[:12])
            self.ops.append(("begin", addr, nwords, ram))
            self._flash_addr, self._remaining, self.state = addr, nwords, 2
            return OK, b""
        if op == 7:
            if self.state != 2:
                return BAD_STATE, b""
            n = len(a) // 2
            if n == 0 or len(a) % 2 or n > self._remaining:
                self.state = 1
                return BAD_ARG, b""
            if self.fail_flash_after is not None and self._written + n > self.fail_flash_after:
                self.state = 1
                return TIMEOUT, b""
            for i, b in enumerate(a):  # flash can only clear bits
                x = self._flash_addr + i
                self.mem[x] = self.mem.get(x, 0xFF) & b
            self._flash_addr += len(a)
            self._remaining -= n
            self._written += n
            return OK, b""
        if op == 8:
            if self.state != 2:
                return BAD_STATE, b""
            self.state = 1
            self.ops.append(("end",))
            return (OK if self._remaining == 0 else BAD_STATE), b""
        return UNKNOWN_OP, b""
```

```python
"""Memory layout of the supported MSP430 devices."""
from __future__ import annotations

from dataclasses import dataclass


@dataclass(frozen=True)
class Device:
    name: str
    device_id: int  # word at DeviceIdPointer + 4, as read (little-endian)
    main_start: int
    main_end: int  # exclusive
    segment_size: int  # main flash erase segment
    info_segments: tuple  # ((start, size), ...): the writable information segments
    ram_start: int  # where the flash funclets are loaded

    def region(self, addr: int):
        """(start, end) of the programmable region that holds addr, or None."""
        if self.main_start <= addr < self.main_end:
            return (self.main_start, self.main_end)
        for start, size in self.info_segments:
            if start <= addr < start + size:
                return (start, start + size)
        return None

    def in_main(self, addr: int) -> bool:
        return self.main_start <= addr < self.main_end

    def erase_base(self, addr: int) -> int:
        """Start of the erase segment that holds addr (addr must be programmable)."""
        if self.in_main(addr):
            return addr - (addr - self.main_start) % self.segment_size
        return self.region(addr)[0]

# absent: the tool never writes them.

    main_end=0x24400,
    segment_size=512,
    info_segments=((0x1800, 128), (0x1880, 128), (0x1900, 128)),
    ram_start=0x2400,
)

DEVICES = {d.device_id: d for d in (MSP430F5529,)}
```

```python
"""USB access to the probe and the client side of the SBW vendor command (0x90).

Wire format, all fields little-endian:
    request:  [0x90][op][args...]      response: [0x90][status][data...]

The probe's bulk endpoints never send or expect zero-length packets, so a
packet whose length is a multiple of 64 bytes would not terminate the USB
transfer. `chunks()` picks word counts that avoid such lengths.
"""
from __future__ import annotations

import struct
from dataclasses import dataclass

VID, PID = 0x2E8A, 0x000C
VENDOR_CMD = 0x90
PROTOCOL_VERSION = 1
USB_PACKET = 64

OP_INFO, OP_CONNECT, OP_DISCONNECT, OP_READ_MEM, OP_WRITE_MEM = 0, 1, 2, 3, 4
OP_ERASE, OP_FLASH_BEGIN, OP_FLASH_DATA, OP_FLASH_END = 5, 6, 7, 8

ENTRY_NORMAL, ENTRY_MAGIC_PATTERN = 0, 1
ERASE_SEGMENT, ERASE_BANK, ERASE_MAIN = 0, 1, 2

STATUS_OK = 0
STATUS_NO_TARGET = 4
STATUS_NAMES = {
    0: "OK",
    1: "BAD_ARG",
    2: "BAD_STATE",
    3: "BUSY (the SWD port is in use)",
    4: "NO_TARGET",
    5: "LOCKED (the JTAG lock key is programmed)",
    6: "TARGET_ERROR (lost synchronization with the CPU)",
    7: "TIMEOUT (no answer from the target)",
    8: "UNKNOWN_OP",
}


class ProbeError(Exception):
    """Talking to the probe failed."""


class StatusError(ProbeError):
    """The probe answered a command with a non-zero status."""

    def __init__(self, op: int, status: int, data: bytes = b""):
        name = STATUS_NAMES.get(status, f"status 0x{status:02X}")
        super().__init__(f"command 0x{op:02X} failed: {name}")
        self.op = op
        self.status = status
        self.data = data


@dataclass(frozen=True)
class Info:
    version: int
    state: int
    max_data_bytes: int
    features: int


@dataclass(frozen=True)
class Identity:
    jtag_id: int
    core_id: int
    device_id_ptr: int
    device_id: int


def chunks(nwords: int, header_bytes: int, limit_words: int):
    """Yield word counts that add up to nwords, each at most limit_words and
    each giving a packet (header + data) that is not a multiple of 64 bytes."""
    while nwords > 0:
        n = min(nwords, limit_words)
        if n > 1 and (header_bytes + 2 * n) % USB_PACKET == 0:
            n -= 1
        yield n
        nwords -= n


class UsbTransport:
    """The probe's CMSIS-DAP v2 bulk interface (interface 0)."""

    def __init__(self, serial: str | None = None):
        import usb.core
        import usb.util

        self._usb_util = usb.util
        devs = list(usb.core.find(find_all=True, idVendor=VID, idProduct=PID))
        if serial is not None:
            devs = [d for d in devs if d.serial_number == serial]
        if not devs:
            raise ProbeError(f"probe {VID:04x}:{PID:04x} not found")
        if len(devs) > 1:
            found = ", ".join(d.serial_number for d in devs)
            raise ProbeError(f"several probes found ({found}); choose one with --serial")
        self._dev = devs[0]

        intf = self._dev.get_active_configuration()[(0, 0)]
        self._out = next((e.bEndpointAddress for e in intf if not e.bEndpointAddress & 0x80), None)
        self._in = next((e.bEndpointAddress for e in intf if e.bEndpointAddress & 0x80), None)
        if self._out is None or self._in is None:
            raise ProbeError("bulk endpoints not found on interface 0")
        try:
            if self._dev.is_kernel_driver_active(0):
                self._dev.detach_kernel_driver(0)
        except NotImplementedError:
            pass  # macOS
        try:
            usb.util.claim_interface(self._dev, 0)
        except usb.core.USBError as e:
            raise ProbeError(
                f"cannot claim the probe's DAP interface ({e}); is openocd or another tool using it?"
            ) from None

    def transfer(self, request: bytes, timeout_ms: int = 3000) -> bytes:
        self._dev.write(self._out, request, timeout=timeout_ms)
        return bytes(self._dev.read(self._in, 1024, timeout=timeout_ms))

    def close(self) -> None:
        self._usb_util.release_interface(self._dev, 0)
        self._usb_util.dispose_resources(self._dev)


class SbwProbe:
    """Client for the firmware's msp430::Session."""

    def __init__(self, transport):
        self._t = transport
        self.max_words = 16
        self.read_words = 16
        self.write_words = 16

    def _cmd(self, op: int, payload: bytes = b"") -> bytes:
        resp = self._t.transfer(bytes([VENDOR_CMD, op]) + payload)
        if len(resp) < 2 or resp[0] != VENDOR_CMD:
            raise ProbeError(
                "the probe does not answer the MSP430 SBW command; its firmware is "
                "too old or was built without CONFIG_PROBE_MSP430_SBW"
            )
        if resp[1] != STATUS_OK:
            raise StatusError(op, resp[1], resp[2:])
        return resp[2:]

    def dap_disconnect(self) -> None:
        """Standard DAP_Disconnect: make sure the SWD port has released the pins."""
        self._t.transfer(b"\x03")

    def info(self) -> Info:
        info = Info(*struct.unpack("<BBHI", self._cmd(OP_INFO)[:8]))
        self.max_words = info.max_data_bytes // 2
        return info

    def configure(self, speed_khz: int) -> None:
        """Size the data commands so that each takes roughly 100 ms on the probe."""
        self.read_words = min(self.max_words, max(32, speed_khz * 5 // 4))
        self.write_words = min(self.max_words, max(32, speed_khz * 3 // 8))

    def connect(self, speed_khz: int, entry_mode: int) -> Identity:
        data = self._cmd(OP_CONNECT, struct.pack("<HB", speed_khz, entry_mode))
        return Identity(*struct.unpack("<BHIH", data[:9]))

    def disconnect(self) -> None:
        self._cmd(OP_DISCONNECT)

    def read_mem(self, addr: int, nwords: int) -> bytes:
        out = bytearray()
        for n in chunks(nwords, 2, self.read_words):
            out += self._cmd(OP_READ_MEM, struct.pack("<IH", addr + len(out), n))
        return bytes(out)

    def write_mem(self, addr: int, data: bytes) -> None:
        off = 0
        for n in chunks(len(data) // 2, 6, self.write_words):
            self._cmd(OP_WRITE_MEM, struct.pack("<I", addr + off) + data[off:off + 2 * n])
            off += 2 * n

    def erase(self, mode: int, addr: int, ram_addr: int) -> None:
        self._cmd(OP_ERASE, struct.pack("<BII", mode, addr, ram_addr))

    def flash_begin(self, addr: int, nwords: int, ram_addr: int) -> None:
        self._cmd(OP_FLASH_BEGIN, struct.pack("<III", addr, nwords, ram_addr))

    def flash_data(self, data: bytes) -> None:
        """One FLASH_DATA command; the caller splits with chunks(..., 2, write_words)."""
        self._cmd(OP_FLASH_DATA, data)

    def flash_end(self) -> None:
        self._cmd(OP_FLASH_END)
```

```python
"""Erase / program / verify flow on top of SbwProbe."""
from __future__ import annotations

import devices
import image
import probe as probe_mod
from probe import StatusError

NORMAL_ENTRY_TRIES = 4  # TI GetCoreID: MAX_ENTRY_TRY


class FlashError(Exception):
    """A step of the flow failed; the message is meant for the user."""


def open_session(probe, speed_khz: int):
    """Connect to the target: normal entry up to four times, then once with the
    magic-pattern entry. Returns (Identity, Device)."""
    probe.dap_disconnect()
    info = probe.info()
    if info.version != probe_mod.PROTOCOL_VERSION:
        raise FlashError(
            f"probe speaks SBW protocol version {info.version}, this tool needs "
            f"version {probe_mod.PROTOCOL_VERSION}"
        )
    probe.configure(speed_khz)

    attempts = [probe_mod.ENTRY_NORMAL] * NORMAL_ENTRY_TRIES + [probe_mod.ENTRY_MAGIC_PATTERN]
    last = None
    for mode in attempts:
        try:
            identity = probe.connect(speed_khz, mode)
            break
        except StatusError as e:
            if e.status != probe_mod.STATUS_NO_TARGET:
                raise FlashError(str(e)) from None
            last = e
    else:
        jtag_id = last.data[0] if last.data else 0
        hint = "the data line stayed high: nothing is connected" if jtag_id == 0xFF else \
            "check the wiring, the target supply and try a lower --speed"
        raise FlashError(f"no MSP430 found (JTAG ID read as 0x{jtag_id:02X}); {hint}")

    device = devices.lookup(identity.device_id)
    if device is None:
        raw = identity.device_id
        raise FlashError(
            f"unsupported device: ID bytes {raw & 0xFF:02X}h {raw >> 8:02X}h at "
            f"0x{identity.device_id_ptr + 4:05X} (JTAG ID 0x{identity.jtag_id:02X}); "
            "add it to tools/msp430/devices.py"
        )
    return identity, device


def validate(device, segments) -> None:
    """Every byte must lie in main flash or a writable information segment."""
    for seg in segments:
        addr = seg.addr
        while addr < seg.end:
            region = device.region(addr)
            if region is None:
                raise FlashError(
                    f"image has data at 0x{addr:05X}, outside the programmable flash of "
                    f"{device.name} (main 0x{device.main_start:05X}-0x{device.main_end - 1:05X}, "
                    "information segments B-D)"
                )
            addr = region[1]


def plan_erase(device, segments, mode: str):
    """List of (erase mode, address) operations for a validated image."""
    if mode == "none":
        return []
    main_bases, info_bases = set(), set()
    for seg in segments:
        addr = seg.addr
        while addr < seg.end:
            base = device.erase_base(addr)
            if device.in_main(addr):
                main_bases.add(base)
                addr = base + device.segment_size
            else:
                info_bases.add(base)
                addr = device.region(base)[1]
    ops = []
    if mode == "main":
        if main_bases:
            ops.append((probe_mod.ERASE_MAIN, device.main_start))
    else:  # "segments"
        ops += [(probe_mod.ERASE_SEGMENT, base) for base in sorted(main_bases)]
    ops += [(probe_mod.ERASE_SEGMENT, base) for base in sorted(info_bases)]
    return ops


def write_segments(probe, device, segments, progress=lambda done, total: None) -> None:
    total = sum(len(s.data) for s in segments)
    done = 0
    for seg in segments:
        off = 0
        try:
            probe.flash_begin(seg.addr, len(seg.data) // 2, device.ram_start)
            for n in probe_mod.chunks(len(seg.data) // 2, 2, probe.write_words):
                probe.flash_data(seg.data[off:off + 2 * n])
                off += 2 * n
                progress(done + off, total)
            probe.flash_end()
        except StatusError as e:
            raise FlashError(f"programming failed at 0x{seg.addr + off:05X}: {e}") from None
        done += len(seg.data)


def verify_segments(probe, segments) -> None:
    for seg in segments:
        actual = probe.read_mem(seg.addr, len(seg.data) // 2)
        if actual != seg.data:
            i = next(i for i, (a, b) in enumerate(zip(actual, seg.data)) if a != b)
            raise FlashError(
                f"verify failed at 0x{seg.addr + i:05X}: read 0x{actual[i]:02X}, "
                f"expected 0x{seg.data[i]:02X}"
            )


def program(probe, device, segments, erase: str = "main", verify: bool = True,
            progress=lambda done, total: None) -> None:
    """Erase, write and verify. The session must be open."""
    segments = image.pad_to_words(segments)
    validate(device, segments)
    for mode, addr in plan_erase(device, segments, erase):
        try:
            probe.erase(mode, addr, device.ram_start)
        except StatusError as e:
            raise FlashError(f"erase at 0x{addr:05X} failed: {e}") from None
    write_segments(probe, device, segments, progress)
    if verify:
        verify_segments(probe, segments)
```

```python
#!/usr/bin/env python3
"""Program an MSP430F5529 over Spy-Bi-Wire with a debugprobe-zephyr probe.

    sbw.py info
    sbw.py flash firmware.hex [--erase main|segments|none] [--no-verify]
    sbw.py erase [--segment ADDR]
    sbw.py read ADDR LENGTH -o dump.hex
    sbw.py verify firmware.hex
    sbw.py reset

Every command resets the target. See docs/MSP430_SBW.md for wiring.
"""
from __future__ import annotations

import argparse
import sys

import flasher
import image
import probe as probe_mod
from flasher import FlashError
from image import ImageError, Segment
from probe import ProbeError, SbwProbe


def _int(text: str) -> int:
    return int(text, 0)


def _parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(prog="sbw.py", description="MSP430F5529 Spy-Bi-Wire programmer")
    p.add_argument("--speed", type=int, default=250, metavar="KHZ",
                   help="SBW clock in kHz, 100-1000 (default 250)")
    p.add_argument("--serial", help="USB serial number of the probe")
    sub = p.add_subparsers(dest="cmd", required=True)

    sub.add_parser("info", help="identify the target")

    f = sub.add_parser("flash", help="erase, program and verify an image")
    f.add_argument("image", help="Intel HEX or TI-TXT file")
    f.add_argument("--erase", choices=("main", "segments", "none"), default="main",
                   help="main: erase all main flash (default); segments: only the "
                        "segments the image touches; none: do not erase")
    f.add_argument("--no-verify", action="store_true", help="skip the read-back")

    e = sub.add_parser("erase", help="erase all main flash, or one segment")
    e.add_argument("--segment", type=_int, metavar="ADDR",
                   help="erase only the segment that contains ADDR")

    r = sub.add_parser("read", help="dump memory to a file")
    r.add_argument("addr", type=_int)
    r.add_argument("length", type=_int, help="number of bytes")
    r.add_argument("-o", "--out", required=True, help=".bin for raw bytes, otherwise Intel HEX")

    v = sub.add_parser("verify", help="compare flash contents with an image")
    v.add_argument("image")

    sub.add_parser("reset", help="reset the target and let it run")
    return p


def _progress(out):
    def show(done: int, total: int) -> None:
        out.write(f"\rprogramming {done}/{total} bytes")
        out.flush()
    return show


def _run(args, probe: SbwProbe, out) -> None:
    if not 100 <= args.speed <= 1000:
        raise FlashError("--speed must be between 100 and 1000 kHz")
    identity, device = flasher.open_session(probe, args.speed)
    try:
        out.write(f"{device.name}: JTAG ID 0x{identity.jtag_id:02X}, core ID "
                  f"0x{identity.core_id:04X}, device ID bytes {identity.device_id & 0xFF:02X}h "
                  f"{identity.device_id >> 8:02X}h\n")
        if args.cmd == "flash":
            segments = image.load(args.image)
            flasher.program(probe, device, segments, erase=args.erase,
                            verify=not args.no_verify, progress=_progress(out))
            size = sum(len(s.data) for s in segments)
            out.write(f"\nprogrammed {size} bytes" +
                      ("" if args.no_verify else ", verified") + "\n")
        elif args.cmd == "erase":
            if args.segment is None:
                probe.erase(probe_mod.ERASE_MAIN, device.main_start, device.ram_start)
                out.write("erased main flash\n")
            else:
                if device.region(args.segment) is None:
                    raise FlashError(f"0x{args.segment:05X} is not in programmable flash")
                base = device.erase_base(args.segment)
                probe.erase(probe_mod.ERASE_SEGMENT, base, device.ram_start)
                out.write(f"erased the segment at 0x{base:05X}\n")
        elif args.cmd == "read":
            if args.addr & 1 or args.length <= 0:
                raise FlashError("the address must be even and the length positive")
            data = probe.read_mem(args.addr, (args.length + 1) // 2)[:args.length]
            image.save(args.out, [Segment(args.addr, data)])
            out.write(f"read {len(data)} bytes from 0x{args.addr:05X} into {args.out}\n")
        elif args.cmd == "verify":
            segments = image.pad_to_words(image.load(args.image))
            flasher.verify_segments(probe, segments)
            out.write("verified\n")
        # "info" and "reset" need nothing more: the session itself resets the target.
    finally:
        try:
            probe.disconnect()
        except ProbeError:
            pass


def main(argv=None, transport=None, out=sys.stdout, err=sys.stderr) -> int:
    args = _parser().parse_args(argv)
    try:
        t = transport if transport is not None else probe_mod.UsbTransport(args.serial)
        try:
            _run(args, SbwProbe(t), out)
        finally:
            t.close()
    except (ProbeError, FlashError, ImageError, OSError) as e:
        err.write(f"error: {e}\n")
        return 1
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

````markdown
# Programming an MSP430F5529 over Spy-Bi-Wire

The probe can erase, program, verify and read an MSP430F5529 through its
two-wire Spy-Bi-Wire (SBW) interface. It uses the same two pins as SWD and the
same USB interface; the SWD/CMSIS-DAP function is unchanged. Debugging
(breakpoints, single-step) is not implemented yet.

## Wiring

| Probe board | SBWTCK → target TEST | SBWTDIO ↔ target RST | Ground |
|---|---|---|---|
| Raspberry Pi Pico / Pico 2 | GP2 | GP3 | any GND pin |
| Raspberry Pi Debug Probe | "D" connector SC | "D" connector SD | "D" connector GND |

Keep the wires short (10–20 cm). The target must be powered by its own supply.

## Check before you connect

1. **Measure the target's VCC.** The probe drives 3.3 V. If the target runs
   below 3.0 V, do not connect it directly; the MSP430's pins tolerate at most
   VCC + 0.3 V.
2. **Look at the RST pin circuit.** TI recommends about 47 kΩ to VCC and at
   most 2.2 nF to ground. A larger capacitor slows the data line; lower the
   speed (`--speed 100`), and if that is not enough, the capacitor has to go.
3. **Do not leave an unpowered probe attached to a powered target.** The
   RP2040's protection diodes then load RST and TEST and can hold the target
   in reset.
4. **Do not run SWD tools (openocd, probe-rs) against the probe while an
   MSP430 is attached.** They drive the same two pins.

## Usage

```bash
pip install -r tools/msp430/requirements.txt

python3 tools/msp430/sbw.py info
python3 tools/msp430/sbw.py read 0x4400 0x20000 -o backup.hex   # back up main flash
python3 tools/msp430/sbw.py flash firmware.hex
python3 tools/msp430/sbw.py verify firmware.hex
python3 tools/msp430/sbw.py erase
python3 tools/msp430/sbw.py reset
```

Images are Intel HEX or TI-TXT. Convert an ELF file with
`msp430-elf-objcopy -O ihex firmware.elf firmware.hex`.

`flash` erases all main flash (`0x4400`–`0x243FF`), programs the image, reads
it back and resets the target. Options:

- `--erase segments` erases only the 512-byte segments the image touches;
  `--erase none` erases nothing.
- `--no-verify` skips the read-back.
- `--speed KHZ` (before the command) sets the SBW clock, 100–1000 kHz,
  default 250. 500 kHz is the rate of TI's reference implementation.
- `--serial SERIAL` selects one of several probes.

Information segments B, C and D (`0x1800`–`0x197F`) are erased and written only
when the image contains data for them. Information segment A and the bootloader
area (`0x1000`–`0x17FF`) are never written; an image that addresses them is
rejected before anything is erased.

**Every command resets the target**, including `info` and `read`: taking
control of the CPU involves a power-on reset, and releasing it a JTAG reset.

### Speed

| `--speed` | Programming | Read-back |
|---|---|---|
| 250 kHz (default) | about 2 kB/s | about 6 kB/s |
| 500 kHz | about 4 kB/s | about 12 kB/s |
| 1000 kHz | about 7 kB/s | about 24 kB/s |

## Troubleshooting

| Message | Likely cause |
|---|---|
| `no MSP430 found (JTAG ID read as 0xFF)` | The data line stayed high: nothing connected, or TEST/RST swapped. |
| `no MSP430 found (JTAG ID read as 0x..)` | Marginal signal: shorten the wires, check the RST capacitor, lower `--speed`. |
| `BUSY (the SWD port is in use)` | An SWD debugger is connected through the same probe. |
| `LOCKED` | The device's JTAG lock key is programmed. This tool does not unlock devices. |
| `unsupported device: ID bytes ..` | The target is not an MSP430F5529. |
| `verify failed at 0x…` | The flash was not erased first (`--erase none`), or the signal is marginal: lower `--speed`. |
| `the probe does not answer the MSP430 SBW command` | The probe firmware is older than this feature or was built with `CONFIG_PROBE_MSP430_SBW=n`. |

## How it works

`drivers/sbw_pio` clocks JTAG cycles onto the two wires with a PIO program on
PIO1. `lib/msp430` implements the JTAG sequences of TI's SLAU320 reference
(`Replicator430Xv2`) and exposes them through CMSIS-DAP vendor command `0x90`.
Flash is erased and written by TI's RAM funclets, which run on the target and
exchange data through the JTAG mailbox. The design is described in
`docs/superpowers/specs/2026-11-11-msp430-sbw-design.md`.
````
